# Leonardo Benicio — Newsletter

**Current version:** `2.0.10`

The newsletter landing page for Leonardo Benicio, built with Hugo and the [AboutMe v2 theme](https://github.com/lbenicio/theme). GitHub Actions deploys this static site to Cloudflare Workers. Configure the repository secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`; the Worker serves the site on its custom domain.

Run a local preview with `hugo server`.
